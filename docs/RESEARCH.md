# Phase 1 — Research Plan

## Questions
- What prevents a distressed person from using a conventional application?
- When is voice easier than touch/UI navigation?
- When is video useful or harmful?
- What communication patterns are safe?
- What should trigger human escalation?
- What data is actually necessary?
- How should consent work when a user is distressed?

## Outputs
- Problem statement
- User journeys
- Accessibility requirements
- Safety requirements
- Privacy/data map
- MVP acceptance criteria
