# MANORAKSHA V16.2 — AI Camera Lifecycle + Light Theme Readability

## Included fixes

### AI camera lifecycle
- When the MANORAKSHA AI screen mounts, the browser requests camera permission automatically.
- The camera stream remains hidden from the UI and is used only for the existing optional frame capture path.
- When the AI screen unmounts/leaves, all camera tracks are stopped and the video source is cleared.
- The existing manual camera button remains available for retrying after a denied/unavailable permission state.
- Camera permission is never silently bypassed; the browser permission prompt controls access.

### Light theme readability
- AI replies now use high-contrast dark text on a warm light reply card.
- MANORAKSHA AI helper/status text is darker and easier to read.
- Support empty-state copy is readable in light mode.
- Reviews & Feedback title, prompt, success message, history metadata, and form content use stronger contrast.
- Support card titles, descriptions, and actions receive light-theme contrast overrides.

## Changed files
- `frontend/src/main.jsx`
- `frontend/src/styles.css`
- `frontend/package.json` (version 0.16.2)

No backend or database changes are included in V16.2.
